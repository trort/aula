# 学习岛（aula）· 阶段记录 v0.29（2026-09-07）

> 给"隔一段时间再接手"的人/模型看的项目快照。线上地址：https://trort.github.io/aula/

## 现在是什么

纯前端 PWA（Vite + React + TS + localStorage + Service Worker），GitHub Pages 自动部署（push main 即发布）。仓库：`trort/aula`，本地根目录即本仓库。App 内版本号显示在首页右下角（如 v0.29），与 `package.json` / `public/sw.js` 缓存名同步递增。

## 已实现（截至 v0.29）

- 双领域首页：识字岛 / 数学岛。
- **自动进阶引擎**（识字 & 数学共用 `src/lib/progress.ts`）：
  - 每字/每难度有连续掌握分 0–1（净答对 3 次=满分）；
  - 渐进混合：前一档约 50% 才开始混入下一档、90% 放量；旧内容保留复习权重；
  - 孩子不选字表/难度，只选 5/10/15 题。
- 识字四种玩法（首页可选，自动从当前课程选字）：
  1. 听音选字（卡片）；
  2. 找茬 3×3 —— **不计入识字掌握进度**（纯观察力，仍计本轮成绩/星星）；
  3. 传送带气球连句（≥4 字真实短语拼句，掌握 30 字后解锁；点对只消失那个气球、动物开心；点错气球保留、动物不开心、可重试；句尾按短语朗读）；
  4. 迷雾寻字（单幅随机暗幕 + Canvas 像素级刮开判定 + 拖进答案筐）。
- 数学：L1–L6 规则生成器；键盘填空作答；晓晓本地片段拼接语音（数字 0–99 + 加/减/等于/几）。
- 语音策略：单字/整词优先本地晓晓 mp3；缺失才回退系统 TTS；多音字在句子里按**短语音频**朗读（如"高兴"里的 兴）。
- 奖励：星星罐、动物贴纸簿、完美徽章、连击🔥、粒子与 WebAudio 音效；三种记录模式共享同一套逐字进度。
- 家长数据页：建议复习、逐字记录、字表进度、各难度掌握、练习历史、JSON 导出/导入。

## 内容规则（v0.33 起，加字/加题前必看）

完整说明见 [content-rules.md](content-rules.md)，一句话版本：

1. **听音类玩法（听音选字 / 迷雾寻字 / 连句喂食）的选项里不能有与目标字同音的字**（不计声调）。
   2026-09-11 排查出的 10 组：站/占、坐/座、快/块（完全同音）+ 风/凤、花/华、又/友、白/百、跑/泡、跳/挑、爸/巴（仅声调）。
   手工干扰项保留（找茬模式还要用），听音类出题时由 `src/lib/decoys.ts` 自动跳过。
2. 干扰项：形状像第一，其次优先"同期学过 / 已学过"的字；
   优先级由 `src/lib/decoys.ts` 出题时自动执行（同单元 → 已学单元 → 更晚单元 → 只当过干扰字的字，层内随机），
   已有数据不重写（2026-09-11 决定：这是 minor detail，只约束以后新增的内容）。
3. 读音表放在 `src/data/pinyin.ts`（新增字必须补读音），改完跑 `npm run check:content`（`npm run build` 已内置）。

## v0.36：家长模式（验证题 + 手动改进度）

- 进入家长数据页要先解一道**一元一次方程**（如 4x + 7 = 31；加减法小朋友学得快，所以用解方程挡），
  答错就换一道新题，乱试无法通过；离开页面自动重新上锁。
- 家长可以按**字**手动标 ✓ 已掌握 / ↺ 没掌握：
  - 已掌握 = 直接记成"练稳"（4 天后安排一次复习）；
  - 没掌握 = 记为刚错，立刻进入"建议今天复习"并在下一轮优先出现（实测：标记后每轮都会被抽到）。
- 字表按包支持"整包标为已掌握 / 整包标为要复习"；数学 L1–L6 每一档也能单独标 ✓ / ↺（含还没练过的档位）。
- 数据仍按字共享（多音字会同时更新它的所有读音条目），改动立即写 localStorage。

## v0.37：家长手动回退 + 数学独立节奏（2026-09-14）

反馈原话（家长）："还没学加法的，题目都已经出到两位数加法甚至减法"，而家长只有 ✓/↺ 两个按钮，
要么把进度标得更超前，要么让难题反复出现，**没有办法把进度往回调**。

1. **新增第三类手动动作：回退（⟲ / ⤺）**
   - 单字 ⟲：清空这个字的记录（回到"没练过"）；字表 ⤺：清空**本字表及之后所有字表**；
     数学 ⤺：清空**本档及之后所有档**（都有二次确认）。
   - 为什么必须"本档也清"：某档是否开启取决于**上一档**的掌握分，只清难题那一档，上一档分高照样把它放出来。
   - 数学面板顺带显示每档"练稳 x%"（对 − 错的净答对进度），家长一眼看出还差多少。
2. **识字与数学的节奏参数分开**（新文件 `src/lib/pace.ts`）：

   | | 净答对满分 | 上一档多少分才混下一档 | 已练稳复习权重 |
   | --- | --- | --- | --- |
   | 识字 | 3 | 50% | 0.25 |
   | 数学 | 15 | 80% | 0.25 |

   - 识字参数原样保留（家长反馈语文节奏合理）；数学 `scoreOf` 的分母从 3 变成 15。
   - 家长标 ✓ 时给的是"满分"，所以 `setMathMastery` 必须一次给到 `net` 次，否则会出现"标了已掌握但进度没到"。
   - 模拟对照（85% 正确率、每轮 10 题）：旧参数第 3 轮出减法、第 6 轮 L1–L6 全出；
     新参数前两轮全是加法，第 3 轮开始少量混入进位加法，第 7 轮才出现减法。
3. 新增 [AGENTS.md](../AGENTS.md)：仓库导览（文件职责、核心机制、硬性规则、常见任务入口），
   以后接手的人/agent 不必再从头读整个 repo。

## v0.38：语文/数学节奏按"每天 30 题"重新标定（2026-09-14）

家长给的目标可以直接换算成参数：**语文每天 2–3 个新字；数学约两周一个新概念，最快也要一周**，
外加两条开场豁免：语文前 30 个字一口气放出（否则开头没东西可学），
数学"加法 + 最简单的进位加法"一起放出、比例 90% / 10%。

- **识字改为"新字配额"控制**（`src/lib/pace.ts` 的 `newEvery` / `bootstrapChars`）：
  开头 30 字不限速，之后每 12 题最多 1 个新字（5/10/15 题一局都是每局 1 个），
  其余题量全部用于复习（到期项仍先占最多 40%）。
- **数学改为"时间 + 掌握"双闸门**（`minDays` / `blendStart` / `rampDays` / `maxShare` /
  `warmupLevels` / `warmupShare`），并新增 `planMath()` 统一"放出哪些档、当前主练哪一档"的口径
  （首页、家长页、出题共用，避免显示与实际不一致）。
- `CharStat` 新增 `startedAt`（第一次练的时间，时间闸门用）；旧数据在 `loadState`/`importState` 里补成 `seenAt`。
  家长点 ✓ 会把 `startedAt` 往前推 7 天，保证手动判断立刻生效。
- 模拟实测（85% 正确率、每天各 30 题、10 题一局）：

  | | 实测结果 |
  | --- | --- |
  | 语文 | 第 1–2 天放出 32 字 → 之后稳定 **2.89 个新字/天**；30 天认识 110 字（练稳 95 字） |
  | 数学 | L1+L2 第 1 天同现（90% / 10%）；减法 **第 17 天**、退位减法 **第 30 天**、小侦探 **第 44 天** → 间隔 16 / 13 / 14 天 |

  （数学一开始试过 `net = 300`，实测第 17→24 天间隔偏长，改为 200 后落在两周。
  全对时减法也要第 12–13 天；每天 100 题的全对狂人也要第 8 天——`minDays = 7` 是硬下限。）

## v0.39：传送带气球、找茬报音、平板留白（2026-10-06）

来自家长实测的四条反馈，都在孩子端：

- **传送带（连句喂食）真放干扰气球**：以前补气球时"这句后面的字"先把 4 个名额占满，
  干扰字几乎挤不进来。现在按 `[目标字 → 干扰气球（保证配额）→ 后面的字 → 多余干扰气球]`
  补满槽位，池子里稳定有 1–3 只干扰气球（`src/FeedSentence.tsx`）。
- **气球不再重叠**：气球改成挂在固定"槽位"上、同一速度跑 → 相邻气球永远等距；
  槽位数与气球尺寸随赛道宽度走（窄屏 88px×5 只、平板 124px×6 只）。
  槽位轨道一直挂着，所以中途补进来的气球也跟得上队形，不会挤作一团。
- **气球动画不再卡**：位移从 `left`（每帧重排 + 重绘）改成 `.balloon-track` 的
  `transform: translate3d`（合成层），`will-change: transform`；12 秒一圈的匀速。
- **找茬也报读音**：一进题先读"多数派"那个字，点对后再读混进来那个字
  （`src/LiteracyRunner.tsx`；找茬依旧不计入掌握进度）。
- **平板少留白**：`@media (min-width: 760px)` 起把页面宽度放宽到 920px，
  玩法卡片两列、赛道/动物/句子板一起放大，四周不再空一大圈（`src/styles.css`）。

自检（真机尺寸各扫一遍）：`overlap = 0`，相邻气球间距 224px（平板）/108px（手机），
气球宽 124px / 88px；内容不横向溢出。内容规则检查 3/4/5 只气球池三种规格一起过。

## v0.40：数学两大类题型 —— 填空 + 比大小（2026-10-12）

家长反馈"数学一直是 3+4=几，问法太单一"。出题器改成**两大类题型**，每一档都配比混出
（`src/lib/mathgen.ts` 的 `LEVEL_MIX`）：

- **填空（fill）**：算式挖一个空，数字键盘作答。问法不再只有右边一个空：
  - 普通填空：`3 + 4 = ?`（以前只有这种）
  - 挖空换位置：`? + 4 = 7` / `3 + ? = 7`（减法档是 `12 - ? = 5` / `? - 7 = 5`）
- **比大小（compare）**：点一下大的那一边，不用键盘。
  - 数字比大小：`3 和 4 谁大？`（最简，L1 就有）
  - 算式比大小：`3 + 4 和 2 + 5 谁大？`（减法档比减法，两位数档比两位数）

配比实测（`npm run verify:math`，每档 500 轮）：填空 : 比大小 ≈ 7:3
（L5 小侦探是 8:2，因为它整档都在挖空），所以一局 10 题里大约 3 题是比大小。
比大小**不会出现"一样大"**（两边保证不相等），孩子点一下就出结果。
掌握进度仍按 `L1–L6` 记：比大小题也算在它所属的那一档里，不新增档位、不动存档结构。

- 出题校验脚本 `scripts/verify-math.ts`（`npm run verify:math`）：填空算式填上答案必须成立、
  比大小两边不许相等且 `bigger` 指向真的大的一边、label 能算回 value、数字不超出该档范围。
- 语音：比大小念"三 和 四 谁 大"，用 `math/and.mp3`·`who.mp3`·`big.mp3` 三段晓晓片段拼接。
  **这三段音还没生成**（edge-tts 现在被服务端拒 403），暂时整句回退系统 TTS；
  等能生成时把三个文件丢进 `public/audio/math/` 就会自动切回本地晓晓音，不用改代码。
- 平板/大屏下两张比大小卡片也会一起放大（styles.css 的 760px 断点）。
