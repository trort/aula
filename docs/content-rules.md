# 内容规则（加字、加干扰项、加句子之前必读）

这份文档记录的是一条**踩过坑的规则**，供以后扩充字库/题库时对照。

## 规则 0：数据分三层，加字要三处都动

| 文件 | 管什么 | 加新字时 |
| --- | --- | --- |
| `wordbank/*.json` | 字出现在**哪本书的哪个课次**（数组顺序 = 课程顺序） | 把字加进对应分组的 `chars`；新书就新建一个 json，并在 `src/data/wordbank.ts` 里按顺序拼进来 |
| `src/data/curated.ts` | 每个字的读音、形近干扰项（一字一条） | 新字要加一条 `{ ch, py, pack, decoys }`；`pack` 填它首次出现的分组 id |
| `src/data/pinyin.ts` | 全字表（含只在选项里出现的干扰字）的读音 | 必须补上，漏了 `npm run check:content` 会报错 |

要点：

- **一个字可以同时属于多个字表**（《四五快读》和课本重合很多）。进度按"字"记录，跨书只学一次；
  出题时的"同期/已学优先"按它**最早出现的档位**算（`src/data/wordbank.ts` 的 `firstGroupIndexOf`）。
- 新增一本书就当新的字表文件加在最前面或最后面，别把已有的 `pack` 字段当成员表用。

## 规则 1：听音类玩法的选项里不能有同音字

**问题（2026-09-11 发现）**：听音选字、迷雾寻字里，选项偶尔会同时出现两个读音相同的字
（例如目标是 **站 zhàn**，干扰项里出现了 **占 zhàn**；**坐 zuò / 座 zuò**；**快 kuài / 块 kuài**）。
孩子听到一个音，看到两个"读起来都对"的字，随便点一个就被判错 —— 体验上等于"这题没有正确答案"。

**规则**：凡是**靠听音出题**的玩法，选项里除目标字以外，**不允许出现与目标字读音相同（比较时不计声调）的字**。
不计声调是因为孩子完全没有拼音/声调概念，`bái` 和 `bǎi` 对孩子来说就是"一样的音"。

| 玩法 | 是否受这条规则约束 | 说明 |
| --- | --- | --- |
| 🎧 听音选字（audio） | 是 | 目标字 + 2 个干扰字 |
| 🕯️ 迷雾寻字（scratch） | 是 | 目标字 + 3 个干扰字 |
| 🐻 连句喂食（feed） | 是 | 气球池里不能有目标字的同音气球 |
| 🔍 找茬（imposter） | 否 | 不放音、只比字形，同音字（站/占、坐/座）反而是好陷阱 |

## 规则 2：形近第一，其次优先"同期 / 已经学过"的字

- **形状像**是选干扰字的第一要求（这是本项目的核心设计：逼孩子看笔画差异，而不是靠排除生字蒙对）。
- 在形状相近的候选里，优先用**同期学过、或已经学过的字**，优先级
  **同单元 → 已学过的单元 → 更晚的单元 → 只当过干扰字的字**。
  这条优先级由 `src/lib/decoys.ts` 在出题时自动执行（层内仍然随机），**不需要为了它重写已有数据**：
  - 同样的条件下，先取同单元/已学过的形近字；
  - 手工干扰项（含同音被规则 1 过滤掉的字）不够凑够选项时，从上面这个优先级补位。
- 写新字条时仍然按老办法给 `decoys`：先挑和最像的字（可以含少量"课外"陷阱），
  在此基础上多放几个同期/已学过的形近字，让出题时的优先级有得选。
- 现有 79 条干扰项列表（2026-09-11 之前写的）保持原样，不重写。

## 规则 3：句子短语库

`src/data/sentences.ts` 里的短语：

1. 只能用字库（`src/data/curated.ts`）里已有的字；
2. 同一个短语里不能出现两个**不同的**同音字（否则连句喂食照样会"两个气球都像对的"）。

## 改完必须跑检查

```bash
npm run check:content   # 内容规则守卫，build 之前会自动跑
npm run verify:decoys   # 可选：随机模拟 4 种玩法出题，确认选项里没有同音字/重复项
```

检查内容：

- 每个字（含所有干扰字）都在 `src/data/pinyin.ts` 里有读音 —— 没有读音就无法判断是否同音；
- 每个字表分组里的字都有字条（`src/data/curated.ts`），每个字条的 `pack` 都是真实分组；
- 听音类给每个字留出的"安全干扰字"足够（三选一/四选一）；
- 短语库里的字都在字库内，且短语内部没有同音字；
- 按连句喂食的气球规则走一遍，确认任何时刻都不会出现与当前目标同音的气球。

新增字的流程（原流程见 `docs/phase-log-2026-09-07.md`）：**先定字 → 在 `src/data/pinyin.ts` 补读音 →
写 `decoys`（可用同音字，但只当找茬陷阱）→ 跑 `npm run check:content`**。
