# 词库说明

当前 v0 只放一份"基础字表"（会认字），足够 MVP 起步：

- `grade1-shang-recognition.md`：人类可读版本（家长核对用）。
- `grade1-shang-recognition.json`：结构化版本（按课分组，将来按"组"生成可选字包）。

## 版本说明（重要）

- 表内数据对应统编版（人教版）旧版通用结构，约 300 字，来源为公开整理资料，已交叉核对。
- 2024 秋启用新版教材，一年级上册《识字表》调整为 280 字，且课文/拼音单元结构变化较大。网上现有"新版 280 字表"文本相互矛盾且存在明显转录错误（缺"目"、重复"开"、把"班级/是/拼音"等栏目标题混入字表），不宜直接入库。
- 结论：先用这份基础表开工；等拿到孩子实际使用的课本（或官方电子教材附录页）后，再增量生成"2024 新版字包"，两个版本并行、按教材选择。

## 下一步（数据侧）

1. 给每个字补读音标注（多音字按课文语境取读，如 地 dì/de、长 cháng/zhǎng、着 zhe/zháo）。
2. 按形近关系补充混淆组（如 木本末未、日目白、大太天犬），这是题目生成器 + SRS 的种子数据。
