# 词库说明

课程里用到的字表（**数组顺序 = 课程顺序**，App 会按顺序自动进阶）：

| 文件 | 内容 | 说明 |
| --- | --- | --- |
| `swkd-first.json` | 《四五快读》第一册 | 88 字，家长现在主要用的书，排在课程最前面（5 个包） |
| `grade1-shang-recognition.json` | 一年级上册（统编版） | 原 41 个课次已按"每包 10–30 字"合并成 15 个包 + 小羊上山 2 个包 |
| `grade1-shang-recognition.md` | 一年级上册（人读版） | 家长核对用 |

当前去重后一共 **315 字**，分成 **22 个包**（每包 16–28 字，包内引用 431 条）。

**包大小规则**：每个包 **至少 10 字、最多 30 字**（2026-09-11 合并调整，原来"汉语拼音"那几课一包只有 2–5 字）。
合并后的包用 `mergedFrom` 记录来源课次，`note` 写清包含哪些单元；小的补充表（小羊上山 39 字）从中间拆成两个包。

字音：`public/audio/{字}.mp3`（晓晓神经语音）。新增字后跑 `bash scripts/gen-audio.sh` 自动补齐缺的字音（需要联网 + `pip install edge-tts`）。

**字的归属**：一个字可以同时出现在多本书的字表里（例如"大"既在四五快读第一册、又在课文里）。
字表（JSON）决定"这个字出现在哪些包里"，`src/data/curated.ts` + `src/data/pinyin.ts` 决定"这个字怎么考"（读音、形近干扰项）。
学习进度按**字**记录，所以跨书重复的字只学一次；一轮练习里同一个字也不会出两次题。

## 版本说明（重要）

- 表内数据对应统编版（人教版）旧版通用结构，约 300 字，来源为公开整理资料，已交叉核对。
- 2024 秋启用新版教材，一年级上册《识字表》调整为 280 字，且课文/拼音单元结构变化较大。网上现有"新版 280 字表"文本相互矛盾且存在明显转录错误（缺"目"、重复"开"、把"班级/是/拼音"等栏目标题混入字表），不宜直接入库。
- 结论：先用这份基础表开工；等拿到孩子实际使用的课本（或官方电子教材附录页）后，再增量生成"2024 新版字包"，两个版本并行、按教材选择。

## 下一步（数据侧）

1. 给每个字补读音标注（多音字按课文语境取读，如 地 dì/de、长 cháng/zhǎng、着 zhe/zháo）。
2. 按形近关系补充混淆组（如 木本末未、日目白、大太天犬），这是题目生成器 + SRS 的种子数据。
3. **干扰项不要与目标字同音**（不计声调）：听音类玩法里同音字会让"两个选项都像对的"。
   音频相关玩法会自动跳过同音干扰项，同音字只能留给纯视觉的"找茬"。详见 [../docs/content-rules.md](../docs/content-rules.md)，
   改完跑 `npm run check:content`。
4. 干扰字**形状要像**，其次优先"同期学过 / 已学过"的字（同单元 → 已学单元 → 更晚单元 → 只当过干扰字的字，出题时自动按此优先级取）。
